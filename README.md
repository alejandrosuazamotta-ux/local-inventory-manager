# 🛒 local-inventory-manager

Sistema de escritorio *standalone* para la gestión integral de inventarios, facturación y control de gastos en negocios locales, diseñado para funcionar **100% offline** sin depender de conexión a internet ni servidores externos.

---

### 🌟 Características Principales

* 📦 **Control de Inventario:** Registro, actualización y monitoreo de stock en tiempo real.
* 🧾 **Módulo de Facturación (POS):** Generación rápida de facturas e historial detallado de ventas.
* 💰 **Control de Gastos:** Registro y categorización de egresos para un balance financiero claro.
* 💻 **100% Offline e Instalable:** Funciona como una aplicación ejecutable directamente en el equipo local.

---

### 🛠 Tecnologías Utilizadas

* **Front-end / Interfaz:** HTML5, CSS3, JavaScript, Blade
* **Back-end:** PHP / Laravel
* **Base de Datos:** MySQL / SQLite
* **Distribución:** Aplicación ejecutable local
